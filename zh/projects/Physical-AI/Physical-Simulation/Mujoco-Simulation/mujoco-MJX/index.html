MuJoCo MJX

從 MuJoCo 機器人模擬基礎，進階到 JAX、MJX、向量化 rollouts、domain randomization 與 Playground PPO。

學習目標

  • 理解 MJCF、接觸、相機、控制與逆向運動學
  • 將 MuJoCo model 移植到 MJX
  • 使用 JIT 與 vmap 執行平行 rollouts
  • 訓練 Playground PPO 與 Franka pick-cube 任務

模擬基礎

本節內容

建立後續 MJX 課程需要的模擬與控制基礎。

  • MJX01 — 核心概念與 MJCF

    認識 MuJoCo 核心概念並使用 MJCF 描述機器人。

  • MJX02 — 渲染、相機與接觸

    渲染場景並觀察相機與接觸動力學。

  • MJX03 — 控制與逆向運動學

    使用 damped least-squares IK 控制機械手臂。

  • MJX04 — 從 MuJoCo 到 MJX

    將模擬移植到以 JAX 加速的 MJX。

  • MJX05 — 平行 Rollouts

    向量化 rollouts 並套用 domain randomization。
