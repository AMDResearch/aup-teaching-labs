Genesis Simulation

在 AMD GPU 上使用 Genesis 1.3 建立與控制機器人，從第一個模擬場景一路進階到平行環境。

學習目標

  • 建立 Genesis 場景並載入 Franka Panda 機器人
  • 調整 PD 控制器並讀取機器人狀態
  • 使用逆向運動學完成夾取與放置
  • 將單一場景擴展成 GPU 批次平行環境

Genesis 實作課程

本節內容

從模擬基礎、機器人控制到 GPU 平行模擬的完整路徑。

  • PhySim01 — 初探 Genesis

    初始化 Genesis、建立場景、載入機器人並取得相機影像。

  • PhySim02 — 控制你的機器人

    使用 PD 控制器、調整增益並在重力環境中控制關節。

  • PhySim03 — 運動規劃

    透過逆向運動學與路徑規劃完成接近、夾取與抬升。

  • PhySim04 — 平行模擬

    同時執行多個 Franka 環境，提升實驗吞吐量。
