# AUP Learning Cloud major version every course builds on. One value; '#' starts
# a comment. Teaching-labs CI and the build scripts use the floating base tag
# for this major, which points at its newest final release:
#   GPU targets: ghcr.io/amdresearch/auplc-base:<major>-<target>
#   cpu:         ghcr.io/amdresearch/auplc-default:<major>
#
# Learning Cloud selects the exact release for published course images in its
# own projects/course-base-version.txt. Change this value only when Learning
# Cloud releases a new major version, and fix any course that breaks on it.
# A course that cannot use this base yet may pin a release (vX.Y.Z) in its own
# base-version.override.txt until it is fixed.
