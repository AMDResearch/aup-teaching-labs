# VS Code extensions for this course, installed from Open VSX (code-server's
# marketplace). One extension ID per line; '#' starts a comment. Leave empty
# if the base image already provides everything.
#
# Pin versions (publisher.name@x.y.z) so course builds are reproducible.
# Do not list extensions the base already includes (Learning Cloud's
# dockerfiles/Code/extensions.txt, e.g. ms-python.python, ms-toolsai.jupyter);
# a duplicate extension ID fails the build. Check the base with:
#   docker run --rm --entrypoint ls BASE_IMAGE /usr/lib/code-server/lib/vscode/extensions
#
# Examples:
# ms-vscode.cmake-tools
# llvm-vs-code-extensions.vscode-clangd
